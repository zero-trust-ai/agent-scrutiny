# Tutorials

> **Status:** These tutorials document the *planned* API and usage patterns. Code examples will become runnable when Stage 1 implementation is complete.

Tutorials are hands-on, step-by-step guides. Each one builds a complete, working example.

---

## Available Tutorials

- **[Basic Usage](basic-usage.md)** — Initialize the Scrutinizer, evaluate interactions, and interpret verdicts. The essential starting point.
- **[Plugin Development](plugin-development.md)** — Design, implement, test, and register a custom security plugin from scratch.

## Suggested Reading Order

1. Read [Basic Usage](basic-usage.md) first — it covers the core evaluation loop that everything else builds on.
2. If you want to extend Agent Scrutiny with domain-specific security, move to [Plugin Development](plugin-development.md).
3. For deeper conceptual understanding of *why* things work the way they do, refer to the [Concepts](../concepts/index.md) section.
